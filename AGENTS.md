# Project context

Before changing this project, read `README.md` and `DESIGN.md`.
`DESIGN.md` is the durable record of design decisions, measured versus
provisional dimensions, scope, validation requirements, current exports, and
known risks from the original design conversation.

Treat `optical_setup.scad` as the geometry source of truth. Preserve unrelated
working-tree changes, especially user-selected preview settings. After any
geometry change, run OpenSCAD validation and inspect front, back, left, right,
top, and isometric previews before reporting completion.
